## TASK-022 · ship stages deletions and renames

- Bug (consumer repo): `task ship` failed with `fatal: pathspec 'llms-gateway' did not match any files` when a deletion was already staged (`D `).
- Cause: `commitDirtyWorkingTree` ran `git add -- <every dirty path>`; index-only changes (staged deletion, rename source) match nothing. Non-`-z` porcelain also quoted names with spaces / non-ASCII.
- Fix: parse `git status --porcelain=v1 -z`; `git add -A -- :(literal)<path>` only for untracked / unstaged paths; staged changes are committed as-is.
- Verification: `tests/ship-staging.test.mjs` (4 of 6 failed before); end-to-end ship reproduced with installed 3.1.0 and passes with this build; `pnpm typecheck`, `pnpm test` (96 pass), `pnpm smoke` OK.
- Not released: version still 3.1.0; release needs a version bump + `pnpm publish:npm` (owner).
